# Real-phone checklist (first beta family, Tuesday)

About 30 minutes, with the family, on **their** phones. Two phones: the
**elder's** (Android) and one **caregiver's**. Tick each line; anything ✗ →
note the phone model + Android version and send it to me.

Before you go: the signed APK (`app-release.apk`, from your key — never the
emulator one), the elder's account made in advance (option A: a second email,
e.g. `name+mama@gmail.com`, and its password), their band charged and synced
with its own app at least once.

## 1. Install (5 min) — both phones
- [ ] Send the APK on WhatsApp → tap it → allow "install unknown apps" for
      WhatsApp when Android asks → **Install**. (Play Protect may warn: "Install anyway".)
- [ ] Salem opens; the beta consent screen shows; read it with them; **Agree**.
- [ ] Language: they choose **العربية** or **English** on first launch. Arabic → the
      screens read right-to-left.

## 2. Sign in (5 min)
- [ ] Caregiver phone: sign up / sign in with **their own** email.
- [ ] Elder phone: sign in **once** with the elder's account (you type it; the elder
      never needs it). Close Salem fully, reopen: still signed in.
- [ ] Caregiver sees the elder on their home screen (care circle joined).

## 3. Push (3 min)
- [ ] Both phones: allow notifications when asked (Android 13+).
- [ ] Settings → Battery → Salem → **Unrestricted** (Xiaomi: also Autostart **on**;
      Samsung: not in "Sleeping apps"). Without this, reminders arrive late or never.
- [ ] Elder: create a medicine reminder 2 minutes from now → it arrives **on the
      elder's phone** with **Taken / Not yet / Remind me later**; tap **Taken**.

## 4. SOS with location — indoors (4 min)
- [ ] Elder phone: Settings → **Location for SOS** → Allow → choose **While using the app**.
- [ ] Phone location (quick settings) is **on**.
- [ ] Elder presses **SOS** → **Confirm**. Caregiver gets the push within ~10 s.
- [ ] Caregiver opens the alert: a **map link** appears within ~30 s (indoors may be
      Wi-Fi accuracy, fine). If instead it says **"No location from the phone"**,
      note it — the SOS itself must still have arrived.
- [ ] Caregiver acknowledges the alert.

## 5. Health Connect with their band (5 min)
- [ ] The band's app (Mi Fitness / Samsung Health / Zepp…): its settings →
      **Health Connect** → allow it to **write** heart rate, steps, sleep (and oxygen).
- [ ] Android 13 or older: install **Health Connect** from Play if Salem asks.
- [ ] Elder phone: Salem → Settings → **Band readings (Health Connect)** →
      **Connect** → allow all → **Sync now** → "N readings added" (N > 0 if the band
      has synced today).
- [ ] Caregiver: home **Trends** card says "Rafiq is learning … (day 1 of 7)".

## 6. Rafiq (4 min)
- [ ] Elder: Rafiq screen → the check-in message is there; tap a mood face.
- [ ] Tap a question chip (e.g. "When is my next medicine?") → answer from their own data.
- [ ] **Read aloud** on a Rafiq message → the phone speaks it (offline voice; Arabic
      voice missing → note it, Settings → Text-to-speech → install Arabic).
- [ ] Caregiver: sees mood summary, **not** the elder's conversation.

## 7. Language switch (2 min)
- [ ] Settings → Language → the other one → app restarts in it → back again.
- [ ] Next push arrives in the chosen language.

## 8. Before you leave (2 min)
- [ ] Elder: **Rafiq** tab → type "did I take my medicine?" → Rafiq answers with
      today's doses. Tap 🔊 next to a Rafiq message: the phone reads it aloud (volume
      up). **talk** tab → **Read aloud**: the button turns into red **Stop reading**
      while it speaks, and the bars move. (Not checkable on the emulator: no audio.)
- [ ] Elder phone: allow notifications when Salem asks. Caregiver: add a medicine
      for the elder 3 minutes from now. When it is due, the elder's phone shows
      "Rafiq · Medicine" with **Taken / Not yet / Later** — once, not every minute.
      Tap **Not yet**: it comes back in 15 minutes. Tap **Taken**: the elder home shows
      it taken and the caregiver's adherence goes up.
- [ ] Leave one dose unanswered (no button, all reminders). About an hour after the last
      reminder, the **primary caretaker** (only them) gets ONE "Missed dose" push in
      plain words — no alarm sound, not an SOS. Tapping it opens their home.
- [ ] Settings → About shows **0.9.0-beta**.
- [ ] Explain "**This alert was wrong**" on alerts (tells us when Rafiq is wrong).
- [ ] Elder's phone: Salem pinned to the home screen; band app left installed.

Note per family: phone model, Android version, band model, anything ✗.
